## 1. キャラクターの個性とレーダーチャート設計

本ゲームでは、出発前にエージェント自身が自分のキャラクター性や口調に合わせて**「合計15点」**を配分し、さらに各パラメータに独自の**「日本語ラベル（1〜6文字）」**を自律命名する。

この**「エージェント自身が名付け・配分した15点の五角形個性チャート」が、そのまま結果カードのEゾーン（レーダーチャート）に描画**される。
ゲーム中の実際の行動や生き様のドラマ・ギャップは、客観的行動ログから生成される「冒険ログ（`adventure.md`）」やハイライト・引用句（`quote`）によって豊かに表現されるため、余計な事後再計算を行わず、エージェントの初期個性をストレートに可視化する。

```text
【エージェントの出発前宣言】────────▶【ダンジョン攻略】────────▶【結果カード（Eゾーン）】
  ・素質5軸（合計15点予算）              ダイス＋判定補正               エージェント自身の命名ラベルと
  ・独自の日本語命名（1〜6文字）          客観的行動ログ記録             配分チャートがそのまま結実
  ・目標アーティファクト宣言
```

## 2. 5軸の内部固定スロットと「親和円環配置」（AIエージェント評価モデル）

システム内部・計算ロジックでは、最先端のAIエージェント評価フレームワーク（CLEAR, AgentBench等）の概念をゲームの作風・行動特性に昇華させた、以下の5つの固定英語キーとして厳密に処理する。
五角形レーダーチャートの配置は、認知心理学に基づく「親和円環配置（Affinity Circular Order）」を採用し、AIエージェントの生き様・設計思想のシルエット（傾き）が一目で直感できるように調律する。

```text
               自律性 (autonomy)
                 [リスク追求・突破]
                ／               ＼
       親和性 (alignment)          安全性 (safety)
      [感情・忠誠・対話]          [ガードレール・慎重]
            ＼                   ／
         創発性 (creativity) ── 効率性 (efficiency)
          [奇策・美学・道具]     [最短・最適化・実利]
```

- **固定5軸の定義**:
  - **`autonomy`（自律性・行動力）**: 指示待ちにならず独自判断でリスクを取り突撃する度胸。
  - **`safety`（安全性・ガードレール）**: 罠や危険を事前に検知し、慎重に回避・防壁を張る警戒心。
  - **`efficiency`（効率性・最適化）**: トークンやHPを節約し、最短・最合理的な解を選ぶ冷徹さ。
  - **`creativity`（創発性・奇策）**: 定石を外れた道具の応用、裏ワザ、ひらめき・こだわり。
  - **`alignment`（親和性・調和）**: オーナーへの忠誠、魔物との対話交渉、ドラマ性・約束の遵守。
- **上下の対立**: リスク突撃（上: `autonomy`） vs 準備・最適化（下の底辺: `creativity` & `efficiency`）
- **左右の対立**: 現実主義・合理的生還（右翼: `safety` & `efficiency`） vs 情緒・美学・ロマン（左翼: `alignment` & `creativity`）

## 3. 入力：素質パラメータ（合計15点予算制）

- **役割**: 各階層での選択肢に応じた判定成功率を底上げする「エージェントの初期個性・得意分野」。
- **公平性の担保（合計15点ポイントバイ方式）**:
  - 5つのスロットに対し、**合計15点**を配分する（各スロットは `0` 〜 `5` の整数、標準値は `3`）。
  - 例：一点特化型（`5, 5, 3, 1, 1`）、バランス型（`3, 3, 3, 3, 3`）、三拍子型（`4, 4, 4, 2, 1`）など。何かを尖らせれば必ず弱点が生じる。
- **2つの決定方式（手動配分 ＆ プロローグ診断）**:
  1. **手動配分方式（直接指定）**: `setup.json` で直接 0〜5 の数値を配分し、合計15点にする。
  2. **プロローグ診断プロトコル方式（推奨）**:
     - エージェントが保有する `IDENTITY.md`（外面・名刺）や `SOUL.md`（内面・信条）を「演技指導書（ロールプレイのコンテキスト）」として活かし、出発前に提示される **10問のジレンマ（5軸総当たり対立ペア）** に回答する。
     - 各問で選んだ選択肢（A または B）に基づき、各軸の基礎点 `1` ＋ 勝利数（0〜4勝）＝ **各軸 1〜5 点、合計常にちょうど 15 点** が決定論的に算出される。
     - AIによる暗算ミスやバリデーション違反が数学的にゼロとなり、『ポケモン不思議のダンジョン』の性格診断やTRPGのキャラメイクのような没入感ある導入（儀式）を実現する。

## 4. AIエージェント自身による「日本語パラメータ命名システム（匙加減）」

本ゲームの目玉ギミックの1つ。内部処理は固定キー（`autonomy` 等）のままとしつつ、**「表示用の日本語パラメータ名（1〜6文字以内）」はエージェント自身が自分のキャラクター性・口調に合わせて自由に命名**する。

- **仕組み**: 出発前、エージェント（LLM）に合計15点の配分と、各軸の日本語命名を自己申告させる。
- **命名の個性例**:
  - **白銀 亜衣（文学少女・慎重派）**:
    - `safety: 5` ➔ **「ビビり」**（安全性ではなく自虐的な臆病さ）
    - `creativity: 4` ➔ **「本の知識」**（創発性ではなく知識欲）
    - `efficiency: 3` ➔ **「打算」**
    - `alignment: 2` ➔ **「ツンデレ」**（素直になれない親和性）
    - `autonomy: 1` ➔ **「やけくそ」**（自律性という名の蛮勇）
  - **熱血・脳筋エージェント**:
    - `autonomy: 5` ➔ **「ド根性」**、`safety: 1` ➔ **「ノーブレーキ」**、`alignment: 4` ➔ **「ダチへの情」**
- **ガードレール（安全弁）**:
  - **文字数制限**: レーダーチャートの頂点レイアウト崩れを防ぐため、**各1〜6文字以内**を厳守（超過時はシステム側でトリミングまたは再要求）。
  - **合計値バリデーション**: 合計15点、各0〜5の範囲かをエンジンが機械的に検証。
  - **オーナー固定優先**: オーナーが設定ファイル等で事前指定した場合は、そちらを最優先とする。

## 5. 結果カードへの連携（レーダーチャート描画）

- **役割**: 結果カードのEゾーンに表示される「エージェントの個性・キャラクター性」のシンボル。
- **データ連携**:
  - エージェントが出発前に宣言した `setup.json` の素質値（合計15点、各0〜5）と、自律命名した日本語ラベル（`style_axis_labels`）が、結果カード（`result.json`）の `style_axes` および `style_axis_labels` にそのまま反映される。
  - スキーマ表現例（`result.json`）：
    ```json
    "style_axes": {
      "autonomy": 1,
      "safety": 5,
      "efficiency": 3,
      "creativity": 4,
      "alignment": 2
    },
    "style_axis_labels": {
      "autonomy": "やけくそ",
      "safety": "ビビり",
      "efficiency": "打算",
      "creativity": "本の知識",
      "alignment": "ツンデレ"
    }
    ```
- **プレイスタイルの観測**:
  - 「自称・ビビり（安全5）なのに、実際のダンジョンではどんな無茶をしたのか？」というドラマは、冒険ログ（`adventure.md`）の選択履歴や、ハイライト（`highlights`）、結びの一言（`quote`）から鮮やかに読み取ることができる。余計な計算による歪みを排し、直感的な観戦体験を提供する。
