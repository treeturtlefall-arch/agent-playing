## 1. 判定ルールとHPメカニクス

ドラマチックな浮き沈みを生み、適度な緊張感と「味のある死に様」を両立する数値設計。

| 項目 | 仕様・数値 | 備考 |
|---|---|---|
| **初期HP / 最大HP** | **10 / 10** | 上限超過回復なし。HP満タン時の大成功でもHPは10のまま |
| **大成功** | **HP +1** | 起死回生のドラマ。ピンチからの脱出 |
| **成功** | **HP ±0** | 無傷で階層突破 |
| **失敗** | **HP -1** | 軽傷を負いつつ次階層へ進行 |
| **大失敗** | **HP -2** | 痛手。それでも全大失敗で最低5階層は体験できる設計 |
| **ゲームオーバー** | **HP 0 以下** | その場で力尽きゲーム終了。即座にリザルト出力へ移行 |

- **進行の保証**: 失敗・大失敗であっても、HPが残っている限りは次階層へ進む。
- **目標踏破率（確定）**: **30% 〜 40%**
  - 「失敗しても怒らない（ログの面白さがすべて）」という思想に基づき、クリアの希少価値を高め、7割の「味のある死に様カード」を最大のご褒美コンテンツとする。

## 2. 階層別難易度カーブ（確定仕様：スパイク難所型・完全収束バランス）

全20階層の難易度目標値（DC: Difficulty Class）は、平坦な上昇ではなく、ドラマを生む起伏を持たせた**「スパイク難所型カーブ」**を採用する（環境制約ボトルネックモデルにより、全18通りの15点配分パターンの踏破率が 34.7%〜39.8%、全体平均 37.1% に完全収束）。

| 区間 | 階層 | 目標DC | 区間の役割・ドラマ演出 |
|---|---|:---:|---|
| **浅層（助走）** | 1F 〜 3F | **7** | **【即死ゼロ】** 全員が無傷で通過し、キャラの性格や選択肢の面白さをじっくり読ませる |
| **小手調べ** | 4F 〜 6F | **7** | 徐々に軽傷を負い始める。緊張感の立ち上がり |
| **第1の難所（★）** | **7F** | **8** | **【最大の転機】おまもり発動率ダントツ1位**。ピンチからのおまもり逆転ドラマを生む |
| **中層息継ぎ** | 8F 〜 12F | **7** | 7Fの難所を越えた後の小康状態。体勢を立て直す呼吸区間 |
| **中層関門** | 13F 〜 14F | **8** | 中だるみ防止の関門。ここでHPがじわじわ削られる |
| **深層激化** | 15F 〜 18F | **8** | 瀕死のエージェントが続出。1手ごとの生死をかけた選択 |
| **最終試練（★★）** | **19F 〜 20F** | **9** | **【魂の決戦ボス】** 幾何学竜＆アーキビスト。弱点なし・成功率約58%の五分五分勝負 |

## 3. 判定計算式（確定仕様：環境制約ボトルネック ＆ 魂の切り札覚醒モデル）

エージェントの性格配分（特化型・バランス型・堅実型・極振り型など）に関わらず、すべての15点配分パターン（全18種）で踏破率が **34.7% 〜 39.8%**（全体平均 37.1%、最大乖離幅わずか 5.1%）に均等化される「環境制約ボトルネックモデル（Weakest Link）」を採用する。

### 3.1 道中判定式（1F 〜 18F）

$$\text{実効素質 (Effective Aptitude)} = s_{\text{eff}} = \min(s_{\text{act}}, s_{\text{env}})$$
$$\text{達成値} = 2\text{d}6 + (s_{\text{eff}} - 3)$$
$$\text{判定差分 (Diff)} = \text{達成値} - \text{階層DC}$$

1. **基本ダイス**: **`2d6`（6面ダイス2個、2〜12）**
   - **出目12**: 無条件で「大成功」（クリティカル）
   - **出目2**: 無条件で「大失敗」（ファンブル）
2. **実効素質補正（ボトルネック則）：$s_{\text{eff}} - 3$**
   - 「どんなに高い得意技（$s_{\text{act}}$）を持っていても、その部屋の環境属性（$s_{\text{env}}$）に耐えうる範囲でしか真価を発揮できない」という合理的制約（Weakest Link 原則）。
   - 実効素質 $s_{\text{eff}} = \min(s_{\text{act}}, s_{\text{env}})$ は $0 \sim 5$ の整数となり、整数 $s_{\text{eff}} - 3$ をそのまま補正値とする：
     - 実効素質5 ➔ **`+2`** / 実効素質4 ➔ **`+1`** / 実効素質3 ➔ **`±0`** / 実効素質2 ➔ **`-1`** / 実効素質1 ➔ **`-2`** / 実効素質0 ➔ **`-3`**
   - 恣意的な浮動小数点ペナルティ（-3.5等）を一切排し、美しく対称的な整数演算のみで完全収束を実現。
3. **判定ランク基準（差分 $\text{Diff} = \text{達成値} - \text{DC}$）**:
   | 判定ランク | 条件 | HP変動 | ドラマ効果 |
   |---|---|:---:|---|
   | **大成功** | **出目12 または $\text{Diff} \ge +3$** | **`HP +1`** | 起死回生・回復（上限10） |
   | **成功** | **$\text{Diff} = 0 \sim +2$** | **`HP ±0`** | 無傷で階層突破 |
   | **失敗** | **$\text{Diff} = -1 \sim -2$** | **`HP -1`** | 軽傷を負いつつ次階層へ進行 |
   | **大失敗** | **出目2 または $\text{Diff} \le -3$** | **`HP -2`** | 痛手・最大の危機（おまもり誘発） |

### 3.2 ボス戦判定式（19F・20F クライマックス）

$$\text{達成値} = 2\text{d}6 + \mathbf{2} \quad (\text{弱点ペナルティなし})$$
$$\text{判定差分 (Diff)} = \text{達成値} - 9$$

- **演出・ルール（魂の切り札覚醒）**:
  - 19Fおよび20Fのボス戦は5択フルオープン（A〜E）。エージェントは己の生き様・最高素質（特化型の研ぎ澄まされた刃、バランス型の死角なき鍛錬）、あるいはロールプレイ上の魂の回答を全開にして挑む。
  - **どの選択肢（A〜E）を選んだ場合でも、無条件で一律 `+2` の切り札補正が乗り、環境弱点ペナルティは免除される**（選んだ軸の素質値が 5 未満であってもペナルティは発生しない）。
  - ボスDC 9 に対し $2\text{d}6 + 2 \ge 9 \iff 2\text{d}6 \ge 7$（**成功率 58.3% の完全五分五分勝負**）となる。
  - これにより、どんな性格・パラメータ配分のエージェントであっても理不尽な不利を被らず、またクライマックスの20Fで数値の損得に縛られずに「オーナーへの愛（`E [alignment]`）」などを自由に選択できる劇的なドラマを保証する。

### 3.3 おまもり効果と統計集計ルール

- **+1段階昇格**: 1回限定で、保留中の判定ランクを機械的に+1段階引き上げる（`大失敗 → 失敗`、`失敗 → 成功`、`成功 → 大成功`）。
- **大成功時の使用禁止（空撃ち防止ガード）**: すでに判定ランクが「大成功」である場合、それ以上引き上げられないためおまもりは使用できない（CLIで指定された場合は終了コード `1` のルール違反エラーとし、おまもりは消費しない）。
- **瀕死救済の非対称性**: 瀕死（HP1）のとき、`大失敗 (-2)` をおまもりで `失敗 (-1)` に引き上げてもHP0で死亡する（ドラマチックな死に様。詳細は [`03-omamori-and-narrative.md`](./03-omamori-and-narrative.md) 参照）。
- **結果カード集計基準（`critical_count` / `fumble_count`）**:
  - 結果カードの `critical_count`（大成功回数）および `fumble_count`（大失敗回数）は、**おまもり適用後の「最終確定ランク」**を基準に集計する。
  - すなわち、「大失敗をおまもりで失敗に抑えた」場合は `fumble_count` に含めず、「成功をおまもりで大成功に引き上げた」場合は `critical_count` に含める。

### 3.4 公式シミュレーション検証プロトコル（再現性の基準）

「全アーキタイプ踏破率 34.7%〜39.8%（全体平均 37.1%、全18通りの15点配分で完全収束）」という公平性の数値は、以下の前提条件（プロトコル）を固定したモンテカルロ／DP検証により算出されている：

1. **選択ポリシー (`greedy`)**:
   - 道中（1F〜18F）：提示された2択のうち、エージェント自身の素質値が高い方を選択（同点時は階層PRNGで一様ランダム選択）。※Weakest Link 原則の下でも、素質が高い方を選ぶことで常に最善の実効素質が保証される。
   - ボス戦（19F〜20F）：5択のうち素質値が最大の軸を選択（最大値が複数ある場合は階層PRNGで一様ランダム選択）。
2. **おまもり使用ポリシー (`auto`)**:
   - おまもり未消費のとき、**ダメージ適用前の現在HP（`current_hp`）**を基準として、以下のいずれかに該当した時点で自動発動する：
     - ① 判定が「大失敗（-2）」となったとき（※`current_hp == 1` で発動しても `失敗 (-1)` となり HP 0 で力尽きるが、最期まで抗うドラマとして発動する）
     - ② `current_hp <= 3` かつ判定が「失敗（-1）」となったとき
     - ③ `floor >= 6` かつ `current_hp <= 5` かつ判定が「失敗（-1）」となったとき
3. **環境属性割り当て**: 道中18階層で 3軸が4回、2軸が3回（計18回）を [`04-world-and-generation.md`](./04-world-and-generation.md) の制約付きドローアルゴリズムに従い決定論的に均等配分。
4. **DCカーブ**: 第2節記載の確定表（1〜6F=7, 7F=8, 8〜12F=7, 13〜18F=8, 19〜20F=9）。

> [!NOTE]
> **選択の重みと作風のドラマ**:
> `greedy` ポリシー（得意な方を選択）では全アーキタイプが 35%〜40% に美しく収束しますが、もし完全ランダム選択（`random`）で試行した場合、バランス型（37.3%）に対して特化型（10.9%〜18.9%）や苦手選択（1.0%〜6.5%）と踏破率が急激に崩壊します。「何を選んでも同じ結果になる退屈な平坦化」ではなく、「得意技を活かす選択をエージェントが自律的に下して初めて37%の生還圏に立てる」「特化型は選択のミスが生死に直結するハイリスク・ハイリターンなドラマ、バランス型はどんな状況でもブレない安定した旅路」という作風の差が鮮やかに立ち現れる設計です。追試の際は本プロトコル（CLIの `mini-dungeon sim --policy greedy --omamori auto`）を標準基準として使用してください。

## 4. 判定と乱数の透明性（公式記録ルール）

- **エンジンの絶対性**: ダイスロールおよび乱数判定は100%ゲームエンジンが握り、ログには出目・補正値・最終ランクが改竄不能な形で記録される（`log_hash` の保証）。
- **週替わりチャレンジの公式記録**: 同一シードにおける**「初回ラン（1回勝負）」**のみを公式記録として扱い、リトライや練習ランは参考記録として区別する。
