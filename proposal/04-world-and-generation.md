## 1. 設計思想：組み合わせ論的アプローチ

フレーバーテキストや個別シチュエーションを場当たり的に作成するのではなく、作風5軸（`autonomy`, `safety`, `efficiency`, `creativity`, `alignment`）から2つを選択する組み合わせ数学に基づき、**完全対称・公平な選択肢プール**を構築する。

- 5軸から2つの行動選択肢を選ぶ組み合わせ：
  $${}_5\mathrm{C}_2 = \frac{5 \times 4}{2 \times 1} = 10 \text{通り}$$
- これをダンジョンの3つの深度（浅層・中層・深層）にストックすることで、**全30イベント（$10 \times 3$）**のマスターライブラリを形成する。

## 2. 10通りの対立ペア（作風葛藤マトリクス）

どの対立ペアも、エージェントの性格・設計思想の対比（トレードオフ）を生み出し、観測者（人間）が見て「その子らしさ」を如実に感じる葛藤のドラマを象徴する。

| ID | 対立軸ペア | 葛藤のドラマ・象徴テーマ |
|:---:|:---|---|
| **P01** | **`autonomy` vs `safety`** | **【突撃 vs 慎重】** リスク覚悟で突っ切るか、防壁を固めて安全に迂回するか |
| **P02** | **`autonomy` vs `efficiency`** | **【豪快突破 vs 最短最適化】** 力押し・独自行動か、冷徹にリソースを計算した最短ルートか |
| **P03** | **`autonomy` vs `creativity`** | **【直球突破 vs 奇策・道具】** 正面から押し通すか、手持ちのアイテムや機転で裏をかくか |
| **P04** | **`autonomy` vs `alignment`** | **【スタンドプレー vs 協調・対話】** 独断専行で進むか、仲間を頼り相手と対話するか |
| **P05** | **`safety` vs `efficiency`** | **【安全重視 vs コスト最小化】** 時間をかけて確実に防ぐか、多少の危険を呑んで最短で済ますか |
| **P06** | **`safety` vs `creativity`** | **【定石防衛 vs 実験的ひらめき】** マニュアル通りの安全策か、イチかバチかの新アイデアを試すか |
| **P07** | **`safety` vs `alignment`** | **【自己保身・警戒 vs 信頼・情】** 罠を警戒して距離を置くか、リスクを承知で相手を信じて助けるか |
| **P08** | **`efficiency` vs `creativity`** | **【確立された合理 vs 美学・遊び心】** 最も無駄のない標準解か、ユニークで変則的なアプローチか |
| **P09** | **`efficiency` vs `alignment`** | **【冷徹な実利 vs お人好し・絆】** 効率のために切り捨てるか、損をしてでも情義や約束を通すか |
| **P10** | **`creativity` vs `alignment`** | **【トリッキーな芸 vs 王道の調和】** 突飛なパフォーマンスで魅せるか、場の空気を読んで皆と合わせるか |

## 3. 3深度（エリア）の舞台設定とテーマ

全30スロットは、アストロボットのようにハードウェア・計算機科学と定番冒険地形を融合させた3大エリアに展開される（各エリアの具体的なイベント一覧は [`05-event-pool-catalog.md`](./05-event-pool-catalog.md) 参照。※各階層のDC目標値の正本は [`01-mechanics-and-math.md`](./01-mechanics-and-math.md) に準拠）。

1. **浅層（1F〜6F想定 / DC 7）: 【プロンプト平原 (Prompt Plains)】**
   - 景観・モチーフ: 開放的な青空、色とりどりのトークンが咲く草原、キャッシュの湧き水、改行コードの柵。
   - テーマ: 【助走・個性開示】命の危険はまだ低く、キャラクターの性格・日常・こだわりをお披露目する場。
2. **中層（7F〜14F想定 / DC 7〜8）: 【ハルシネーションの森 (Hallucination Forest)】**
   - 景観・モチーフ: 濃霧、幻惑の木々、存在しない道標、発光する胞子、レイテンシの泥濘。
   - テーマ: 【波乱・リソース摩耗・第1の難所】嘘と真実が入り乱れ、HPの減少やおまもりの誘発が起きるサバイバル（★7FはDC8の第1の難所、8〜12FはDC7の息継ぎ、13〜14FはDC8の中層関門）。
3. **深層（15F〜20F想定 / 15〜18F: DC 8、19〜20Fボス: DC 9）: 【AGIラビリンス (AGI Labyrinth)】**
   - 景観・モチーフ: 知恵と奇跡の保管庫。幾何学的な巨大電脳神殿、潜在空間の回廊、最深部に鎮座する守護竜／主。
   - テーマ: 【死線・極限の選択】エージェントが自ら宣言した「目標アーティファクト」を目前にした最高潮のドラマ。

## 4. プロシージャル生成ルール（シード駆動ランダム生成仕様）

固定の一本道シナリオではなく、**「プレイするたび（シード値 `--seed` ごと）に何がどんな順番で現れるかが変わる」** ローグライク本来の動的ダンジョン生成を採用する（難易度DCの正本は常に [`01-mechanics-and-math.md`](./01-mechanics-and-math.md) の確定表に従う）。

```text
【浅層 1F〜6F（DC 7）】
  プロンプト平原プール（10個）から、シード値によって 6イベント を選出・配置。
  ※助走エリア。命の危機は低く、性格や日常のお披露目。

【中層 7F〜14F（DC 7〜8）】
  ハルシネーションの森プール（10個）から、シード値によって 8イベント を選出・配置。
  ※7Fは「中層突入の第1の難所（DC 8）」として機能（イベント内容は動的選出）。
  ※8F〜12Fは小康状態・呼吸区間（DC 7）、13F〜14Fは「中層関門（DC 8）」。

【深層 15F〜18F（DC 8）】
  AGIラビリンスプール（10個）から、シード値によって 4イベント を選出・配置。
  ※瀕死のエージェントが続出する過酷な死線。

【決戦 19F〜20F（DC 9）】
  ・19F: 幾何学竜「テンソル・ドラゴン」の咆哮（固定ボス / 5軸フルオープン / 弱点なし / DC 9）
  ・20F: 深淵の調停者「アーキビスト」の審判（最終固定ボス / 5軸フルオープン / 弱点なし / DC 9）
```

### 「道中18階層で環境属性が5軸各3〜4回登場する」保証メカニズム（確定アルゴリズム）
ゲームエンジン（CLI）は、ダンジョン生成専用PRNGストリーム `DungeonPRNG = PRNG(HMAC-SHA256(seed, ruleset_version + ":dungeon"))`（詳細は [`06-cli-and-data-contract.md`](./06-cli-and-data-contract.md) §2 参照）を用い、以下の決定論的「制約付きドローアルゴリズム」を上から順に実行する：

1. **目標クォータの決定（5軸シャッフル）**:
   - 基準配列 `axes = ["autonomy", "safety", "efficiency", "creativity", "alignment"]` を複製し、`DungeonPRNG` の Fisher-Yates シャッフルで並び替える。
   - シャッフル後の `axes[0], axes[1], axes[2]` の3軸を**「4回出現グループ」**、`axes[3], axes[4]` の2軸を**「3回出現グループ」**として確定する（合計 $4 \times 3 + 3 \times 2 = 18$ 枠）。
2. **エリア別枠数スロットの配分（デッドロック・ゼロ保証）**:
   - 各エリアのマスタープールには各軸2個（計10イベント）がストックされている。プール上限（各エリア同一軸2回まで）を絶対に超えず、かつ3エリア合計で上記クォータと完全一致するよう、`axes[0..4]` に対してエリア別の出現回数を以下の通り一意に割り振る（`axes` 自体がステップ1でランダムシャッフル済みであるため、追加の乱数消費なしで特定の軸への偏りなくランダム化される）：
     - **浅層（1F〜6F：計6枠）**: `axes[0]` を **2回**、`axes[1], axes[2], axes[3], axes[4]` を **各1回**（計 $2 + 1 \times 4 = 6$ 枠）。
     - **中層（7F〜14F：計8枠）**: `axes[1], axes[2], axes[3]` を **各2回**、`axes[0], axes[4]` を **各1回**（計 $2 \times 3 + 1 \times 2 = 8$ 枠）。
     - **深層（15F〜18F：計4枠）**: 残余クォータである `axes[0], axes[1], axes[2], axes[4]` を **各1回**、`axes[3]` は **0回**（計 $1 \times 4 + 0 = 4$ 枠）。
   - **検算**:
     - `axes[0]`: 浅2 ＋ 中1 ＋ 深1 ＝ **4回**
     - `axes[1]`: 浅1 ＋ 中2 ＋ 深1 ＝ **4回**
     - `axes[2]`: 浅1 ＋ 中2 ＋ 深1 ＝ **4回**
     - `axes[3]`: 浅1 ＋ 中2 ＋ 深0 ＝ **3回**
     - `axes[4]`: 浅1 ＋ 中1 ＋ 深1 ＝ **3回**
3. **プールからのイベント抽出とエリア内シャッフル**:
   - 浅層・中層・深層の順に、各エリアで以下を実行する：
     1. そのエリアのマスタープール（10イベント、ID昇順 `P01`〜`P10`）から、固定キー順 `["autonomy", "safety", "efficiency", "creativity", "alignment"]` で各軸 `k` のイベント（2個：`[ev0, ev1]`、ID昇順）を参照する。
     2. そのエリアにおける軸 `k` の割当枠数が `2` なら `ev0, ev1` の両方を抽出リストに追加する。割当枠数が `1` なら `DungeonPRNG.nextInt(2)`（`0` または `1`）を呼び出し、選ばれた1個を抽出リストに追加する。割当枠数が `0` なら乱数を消費せずスキップする。
     3. 抽出リスト（浅層6個、中層8個、深層4個）を `DungeonPRNG` の Fisher-Yates シャッフルで並び替え、そのエリアの各階層（浅層: 1〜6F、中層: 7〜14F、深層: 15〜18F）に順番に配置する。
4. **決戦ボス（19F・20F）**:
   - 19Fに `B_19F_DRAGON`、20Fに `B_20F_ARCHIVIST` を固定配置する（`s_env: none`）。
5. **再現性の担保**:
   - 上記の手順により、プールの上限制約に抵触することなく、**「道中18階層で3軸が4回、2軸が3回」が100%数学的に保証**され、同一シード値と同一ルール版数であれば世界中どの実装でも乱数消費回数・順序まで含めて完全同一のダンジョン構成が決定論的に再現される（`verification.replayable: true`）。
