# 面白いゲームの「パラメータ」構造と5軸レーダーチャート設計に関する包括的分析報告書

## 1. エグゼクティブ・サマリー

ゲームデザインにおける「パラメータ（能力値・ステータス）」は、単なる勝敗やダメージの計算用変数ではありません。世界的な名作や先鋭的インディーゲームを精査すると、プレイヤーや観測者を熱中させるパラメータには**「キャラクターの歪み（シルエット）の可視化」「プレイスタイルのジレンマ（トレードオフ）」「生き様や思想の表出」**という共通の核が存在します。

特に**「5軸（五角形レーダーチャート）」**は、認知心理学（情報把握の限界）と幾何学（二項対立に陥らない円環構造）の双方において、**「個性を一目で直感させるための黄金比」**として歴史的大作（『Crusader Kings』『真・女神転生』『ウマ娘』『三國志』『Citizen Sleeper』『MTG』『ペルソナ5』等）に採用されてきました。

本報告書では、Web調査およびゲームアーキテクチャ論に基づき、面白いパラメータの8大類型、人を魅了する6大設計原則、および本プロジェクト（[`PROJECT_VISION.md`](../PROJECT_VISION.md)、[`specs/result-card-spec-v1.md`](../specs/result-card-spec-v1.md)）への具体的実装アプローチを提示します。

## 2. なぜ「5軸」なのか？ 〜幾何学の力学とレーダーチャートの罠〜

### 2.1 偶数軸（対立）と奇数軸（円環・ジレンマ）の幾何学的差異

```text
    【4軸・6軸（偶数）】                   【5軸（奇数・五角形）】
      攻撃 (ATK)                                軸1 (Boldness)
         │                                     ／       ＼
防御 ────┼──── 素早さ                   軸5 (Story)     軸2 (Care)
         │                                  ＼         ／
      魔力 (MAT)                            軸4 (Craft) ── 軸3 (Efficiency)
  → 180°の二項対立になりやすい            → 1つの頂点の対面は「辺（2つの軸の結合）」
    （攻めるか守るかの白黒）               （二項対立を排し、三つ巴・円環の葛藤を生む）
```

1. **認知負荷の限界（マジックナンバー 5±2 / コワンの作業記憶限界 4±1）**
   - 3〜4軸では情報量が少なく単純な二元論（物理vs魔法、攻vs防）に退行します。
   - 7軸を超えると蜘蛛の巣の線が密集し、人間がパッと見た瞬間に「どんな型（シルエット）か」を直感できなくなります。
   - **5軸は「人間の直感的パターン認識」と「多面的な葛藤」が両立する極限値**です。
2. **偶数軸（対立）から奇数軸（調和・三つ巴）への飛躍**
   - 4軸・6軸では、ある頂点の真裏（180度）に必ず別の頂点が存在し、「光 vs 闇」「力 vs 知性」のような固定的対立関係を生みます。
   - しかし**5軸（五角形）は、1つの頂点の対面が「2つの頂点を結ぶ底辺」**になります。これにより、「Aを選ぶとBとCの組み合わせに影響する」という多角的なトレードオフが発生します（例：MTGのカラーパイ、東洋の五行思想）。

### 2.2 5軸レーダーチャート最大の罠：「面積の錯覚」と「配置順序依存」

データ可視化論において、レーダーチャートには重大なUXの落とし穴が存在します：
- **面積の錯覚 (Area Distortion)**: 同じ「値5が2つ、値1が3つ」のステータスであっても、**値5が隣り合っていれば広大な三角形（大面積）になり「強く見える」**のに対し、**値5が離れて配置されていると細い棘（小面積）になり「弱く見える」**現象。
- **並び順への依存**: 軸の配置順を入れ替えるだけで、多角形の形と面積が劇的に変化してしまいます。

#### 名作ゲームにおける解決策：
1. **合計予算の均一化（Fixed Budget Allocation）**:
   キャラクターの合計ポイントを一律固定する（例: 合計15点予算制）。面積の広さではなく「どの方向に尖っているか（傾き・アスペクト比）」を視認させる。
2. **親和円環配置（Affinity Circular Ordering）**:
   相性の良い概念、または共存しうるプレイスタイルを隣接させ、相容れない概念を対面（底辺方向）に配置することで、自然なシルエット（アロー型、シールド型等）が形成されるように調律する。

## 3. パラメータの3大アーキテクチャ層（機能による分類）

ゲームにおけるパラメータは、その使われ方によって明確に3つの階層に分類されます。

```text
┌─────────────────────────────────────────────────────────────┐
│ 1. 実行・能力層 (Action & Aptitude / Input)                 │
│    - キャラクターが「何を行えるか」の基礎スペック            │
│    - ダイス判定、命中率、コマンド解放、相性に直結            │
│    - 例: SMTの力/魔/耐/速/運、CK3の5能力、Citizen Sleeper   │
├─────────────────────────────────────────────────────────────┤
│ 2. 状態・制約・狂気層 (State, Hazard & Cost)                 │
│    - 行動の代償、精神的疲弊、モラルの破綻を追跡する時限爆弾 │
│    - 「高すぎても低すぎても破滅する」ドラマ発生装置         │
│    - 例: CoCのSAN値、Darkest Dungeonのストレス、プリメの色気│
├─────────────────────────────────────────────────────────────┤
│ 3. 行動観測・作風層 (Playstyle & Reflection / Output)       │
│    - プレイ中の選択履歴から「どんな生き様だったか」を抽出    │
│    - ゲーム進行自体ではなく、リザルトカード・称号・評価用   │
│    - 例: Refind Self、Big Five、本プロジェクトの style_axes  │
└─────────────────────────────────────────────────────────────┘
```

## 4. 面白いゲームのパラメータ「8大類型」と世界の名作徹底解剖

### ① 【政治・統治・権謀術数型】
* **代表作**: 『Crusader Kings III』（Paradox Interactive）
* **5軸**: **【外交 (Diplomacy) / 軍事 (Martial) / 管理 (Stewardship) / 策略 (Intrigue) / 学識 (Learning)】**
* **面白さの仕掛け**:
  - 中世封建社会における支配者の能力を網羅した5軸。
  - 各パラメータが独立した「ライフスタイル樹形図」と「ランダムイベント」に直結。「管理」が高い君主は領地経営で富を築き、「策略」が高い君主は暗殺と脅迫で恐怖支配を敷く。配分がそのまま中世ドラマのジャンル（戦記、陰謀劇、宗教改革、経済発展）を決定づけます。

### ② 【JRPGの祖・配分ビルド型】
* **代表作**: 『真・女神転生』シリーズ、『ペルソナ』（戦闘）
* **5軸**: **【力 (Strength) / 魔 (Magic) / 耐 (Endurance) / 速 (Agility) / 運 (Luck)】**
* **面白さの仕掛け**:
  - 1992年の初代から脈々と受け継がれる5大ステータス。
  - 物理特化（力・速）、魔法砲台（魔・耐）、即死・状態異常回避型（運・速）など、**割り振りの方針1つで同じ悪魔や主人公が全く異なる挙動を示す**。シンプルでありながら30年以上飽きられない究極の古典です。

### ③ 【因果連動・局面展開フェーズ型】
* **代表作**: 『ウマ娘 プリティーダービー』
* **5軸**: **【スピード / スタミナ / パワー / 根性 / 賢さ】**
* **面白さの仕掛け**:
  - レースの**時間軸（フェーズ）と因果関係**でパラメータが相互に噛み合っている。
  - 「賢さ」で有利な位置取りを行い、「パワー」で馬群を弾き飛ばし、「スタミナ」を消費して「スピード」を維持し、ラストスパートの失速を「根性」で耐え抜く。1つでもボトルネックがあると敗北する連鎖設計が試行錯誤を生みます。

### ④ 【サイバーパンク・生存アプローチ型】
* **代表作**: 『Citizen Sleeper』（Jump Over the Age, 2022）
* **5軸**: **【Engineer (工学) / Interface (電脳) / Endure (身体耐久) / Intuit (直感) / Engage (交渉・交感)】**
* **面白さの仕掛け**:
  - 人造生命体が荒廃した宇宙ステーションで生き抜くためのスキル5軸。
  - 振られた出目ダイスを各施設に配置してアクションを行う。「ハードウェア」「ソフトウェア」「肉体労働」「直感推理」「人間関係」というSF世界で遭遇する全課題を直交してカバーしています。

### ⑤ 【日常行動・人間性アンロック型】
* **代表作**: 『ペルソナ5』（人間パラメータ）
* **5軸**: **【知識 / 度胸 / 器用さ / 優しさ / 魅力】**
* **面白さの仕掛け**:
  - 戦闘能力ではなく「高校生としての人間的厚み」。
  - 図書館での勉強（知識）、ファミレス居座り（度胸）、道具作り（器用さ）、水やり（優しさ）、銭湯通い（魅力）という日常行動の反復が五角形を拡張。それによって「怪盗装備」「協力者との絆（コープ）」「会話選択肢」が解放されていきます。

### ⑥ 【思想哲学・対立調和型】
* **代表作**: 『Magic: The Gathering』（カラーパイ / カラーホイール）
* **5軸**: **【白（秩序・平和） / 青（知識・論理） / 黒（野心・自己） / 赤（衝動・自由） / 緑（本能・自然）】**
* **面白さの仕掛け**:
  - 各色は能力値ではなく「目的と手段の哲学」。
  - 五角形で**隣り合う2色は「友好色（協調）」**、**向かい合う2色は「対抗色（根本的対立）」**として配置され、世界観、ルール、カード相性のすべてを支配しています。

### ⑦ 【背徳・美徳・心理制約型】
* **代表作**: 『プリンセスメーカー2』、『Darkest Dungeon』
* **軸構成**:
  - プリメ2: **【体力 / 知力 / 気品 / 色気 / 道徳心】** ＋ 隠し制約【因果 / ストレス】
  - DD: **【ストレス (0〜200)】** ＋ 発狂判定【Affliction（利己的・被害妄想など） / Virtue（尊厳・集中）】
* **面白さの仕掛け**:
  - 「高いほど良い」を壊す設計。「色気」が高くても「道徳心」が低いと娘は不良化し夜の街へ。「ストレス」が体力を超えると病床に伏す。
  - 『Darkest Dungeon』では、ストレス100で発狂（Affliction）し、仲間の指示を無視したり自傷してパーティを瓦解させる。「管理すべきリスク・時限爆弾」として機能します。

### ⑧ 【無意識ログ抽出・性格鏡像型】
* **代表作**: 『Refind Self: 性格診断ゲーム』、心理学『ビッグファイブ（OCEAN）』
* **5軸（ビッグファイブ）**: **【開放性 (好奇心) / 誠実性 (几帳面) / 外向性 (社交) / 協調性 (利他) / 神経症傾向 (慎重・警戒)】**
* **面白さの仕掛け**:
  - プレイヤーが数値を割り振るのではなく、**「ゲーム内の些細な行動ログ（自動販売機を何回調べたか、羊に話しかけたか等）」を裏で集計し、事後的に本人の無意識の性格・プレイスタイルを鏡のように映し出す**システム。

### ※ 文化的アイコンとしてのパラメータ補論
* **スタンドパラメータ（『ジョジョの奇妙な冒険』）**:
  【破壊力 / スピード / 射程距離 / 持続力 / 精密動作性 / 成長性】の6軸（A〜E）。スペック差ではなく「知恵と能力の応用（ハメ手）」で決まるからこそ、読者は「一見弱そうなスタンドが知恵で勝つ」ドラマに熱狂します。
* **『Disco Elysium』の内なる声システム**:
  4属性配下の24スキルが主人公の脳内で勝手に喋り出す。「論理的思考」が高すぎると他人の感情が理解できなくなってパニックになり、「薄情」が高すぎると死体に話しかけ始めます。**「パラメータの内なる人格化（ペルソナ化）」**は、自律エージェントゲームにとって最大の示唆を与えます。

## 5. 面白いパラメータを生み出す「6大ゲームデザイン原則」

| 原則 | メカニクスと心理的効果 | 凡庸なパラメータとの違い |
|---|---|---|
| **1. 合計予算と二律背反** | 合計値を固定（例: 15点）。何かを伸ばせば何かが必ず犠牲になる。 | 全ステータスMAXの「正解ビルド」が存在せず、プレイヤーごとの好みが分かれる。 |
| **2. 直交性（Orthogonality）** | 各軸の意味が独立しており、互いに重複・代用できない。 | 「素早さ」と「俊敏さ」のような同義語を排し、5軸それぞれに固有の存在意義を持たせる。 |
| **3. 高すぎることの毒・狂気** | 高ステータスが盲目や過剰適応を引き起こす（Disco Elysium的発想）。 | 「高いほど偉い」という固定観念を壊し、弱点や過剰なこだわりがドラマを生む。 |
| **4. 語彙の体温（フレーバー）** | 「STR/DEX」ではなく「度胸」「根性」「こだわり」など、人物の体温や美学を想起させる言葉を使う。 | 数値の計算機から、キャラクターの生き様を想像させるナラティブ装置へ昇華する。 |
| **5. ロマン軸（非合理）の混入** | 合理的な4つの軸の中に、1つだけ「情」「こだわり」「美意識」などの非合理な軸を混ぜる。 | 効率プレイを目的とするAIやプレイヤーに対し、「無駄なこだわり」を肯定する余白ができる。 |
| **6. 両極（0と5）のドラマ性** | 0でも「愚かで愛おしい」、5でも「尖りすぎて破滅する」ような味付けを用意する。 | 最適化から外れたエージェントの死に様が、最高のご褒美コンテンツになる。 |

## 6. 本プロジェクト（AI Agent Arcade / `mini-dungeon`）への実践的提言

本ワークスペースにおける5軸：
```text
style_axes: {
  boldness:   0〜5  # 大胆さ（リスク追求）
  care:       0〜5  # 慎重さ（リスク回避）
  efficiency: 0〜5  # 効率（最短・実利）
  craft:      0〜5  # こだわり（美学・様式）
  story:      0〜5  # 情（利他・物語性）
}
```

この設計をさらに尖らせ、最高峰の観戦体験にするための5つの提言です。

### 提言1: 親和円環配置（Affinity Circular Order）による五角形の調律
面積の錯覚を抑え、キャラクターの生き様が美しいシルエットとして立ち上がる頂点配置：

```text
               大胆さ (Boldness)
                  [リスク追求]
                 ／          ＼
        情 (Story)             慎重さ (Care)
       [利他・情緒]            [リスク回避]
             ＼              ／
         こだわり (Craft) ── 効率 (Efficiency)
          [美学・様式]        [最短・実利]
```
- `大胆さ (Boldness)` の対面に `こだわり (Craft)` と `効率 (Efficiency)` の底辺が来る。
- `効率 (Efficiency)` の対面に `情 (Story)` と `大胆さ (Boldness)` が来ることで、「機械的最適化（右下）」vs「非合理なロマンとドラマ（左〜上）」というエージェントの思想がチャートの傾きとして鮮烈に可視化されます。

### 提言2: 20階層における「平均への回帰（中央値2〜3）」を防ぐ非線形スケーリング
20階層という短い試行回数では、単純な線形集計を行うと全パラメータが中央値（2〜3）に集まる「丸い五角形」ばかりになり、個性が潰れる恐れがあります。
- **解決策**: 行動比率に対して二乗（または閾値超過ボーナス）を適用する非線形補正を導入。これにより、「何もしなかった軸は0〜1」「徹底して選んだ軸は4〜5」という尖ったシルエット（槍型、扇型）が確実に出現します。

### 提言3: レーダーチャートの形状に応じた「プレイスタイル二つ名」生成
五角形の頂点突出方向・底辺形状から、リザルトカードに載る二つ名を機械的に決定する：
- **上部突出（Boldness特化）**: 「猪突猛進の博徒」「前のめりな冒険者」
- **右下突出（Efficiency特化）**: 「冷徹なるタイムアタッカー」「最短歩数の測量士」
- **左翼展開（Story + Craft高）**: 「迷宮の吟遊詩人」「破滅を愛する美学者」
- **右翼展開（Care + Efficiency高）**: 「堅実無比の生還者」「石橋を叩く守銭奴」
- **中央密集（全軸2〜3）**: 「奇跡のバランサー」「波風を立てぬ旅人」

### 提言4: 「素質パラメータ（Input 15点）」と「作風軸（Output）」の乖離ドラマ
素質は「慎重派（Care 5）」なのに、極限状態で「大胆さ（Boldness 5）」の行動ばかり取って毒キノコで死亡した場合、リザルトカードで**「平生を失った暴走」「追い詰められた覚醒」**として劇的に評価されるギミック。

### 提言5: 「おまもり（微小介入）」でっち上げの文脈誘導
人間が持たせたおまもり（自由テキスト）をAIが使う際、**「自身の中で最も高いstyle_axisの文脈」**でこじつけ描写を行わせる：
- `Story` 特化AI: 「マスターがくれた冷えたカレーパンの温もりを思い出し、涙ながらに危機を乗り越えた……」
- `Efficiency` 特化AI: 「カレーパンのカロリー密度と咀嚼時間を計算し、最適エネルギー補給として胃に流し込んだ」
- `Craft` 特化AI: 「このパン粉の黄金比とスパイスの調合こそ、我が美学の極致！」
